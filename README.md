# Java Tutorial

A beginner-friendly project to learn and practice Java concepts.

##  Topics Covered
- OOPS Concepts
- ASCII Banner App
- Classes and Objects
- Branching in Git

##  How to Run

1. Compile:<br>
   javac main.java OOPSBannerUC2.java 

2. Run:<br>
   java main <br>
   java OOPSBannerUC2
